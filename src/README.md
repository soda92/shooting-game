# Island Royale

一个离线单机「吃鸡」原型：**Godot 4.7 + Android**。你和 11 个 AI 跳伞、捡枪、缩圈、活到最后。

没有联网、没有账号、没有内购。APK 约 28 MB。

## 特点

- **12 人局**：1 个玩家 + 11 个 AI，AI 之间也会互相交战
- **程序化岛屿**：高度场地形、水面、树木、岩石，以及 3 个可进入的房区
- **双武器槽**：两把枪独立保存弹匣、备弹和瞄具，0.4 秒切枪
- **瞄具配件**：机瞄 / 红点 / 4 倍 / 8 倍，拾取后在配件面板切换
- **开镜**：第一/第三人称实时切换，狙击镜与红点各有独立表现
- **移动端操作**：虚拟摇杆、左右开火键、闲置自动淡出的按钮
- **战场信息**：小地图、侦察镜、击杀播报、受击方向、爆头提示
- **占位美术与程序化音效**：不依赖外部素材也能直接跑，支持替换为真实资源
