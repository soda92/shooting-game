# 操作与 HUD

## 一局比赛

1. 从 120 米高空跳伞，前 2.6 秒自由落体，之后自动开伞
2. 落地后搜集武器、瞄具、医疗包
3. 安全区分 5 个阶段收缩，圈外持续掉血
4. 活到最后一名获胜；死亡后显示击杀数和名次

## 触屏操作

| 操作 | 位置 |
|---|---|
| 移动 | 左下角虚拟摇杆，推满自动冲刺 |
| 转视角 | 右半屏任意位置拖动 |
| 开火 | 右侧大火键，或左侧小开火键（可同时按） |
| 瞄准 / 开镜 | 右侧「瞄准」 |
| 切换第一/第三人称 | 右侧「视角」，开镜过程中也能切 |
| 换枪 | 底部「切换」 |
| 换弹 / 跳 | 右侧「换弹」「跳」 |
| 医疗 / 侦察 | 右侧「医疗」「侦察」 |
| 配件面板 | 右侧「配件」 |

> 按钮在 2.5 秒内没有触摸时会自动淡到 35%，减少对视野的遮挡；任意触摸立即恢复。

## HUD

- **左上**：小地图（当前圈、下一个圈、玩家朝向、物资、房区）、FPS
- **顶部**：缩圈倒计时与半径
- **右上**：存活数、击杀数、击杀播报、换肤按钮
- **左下**：血量、医疗包数量
- **右下**：双武器槽、弹药、武器名与当前瞄具
- **中央**：准星、命中标记、受击方向弧、侦察标记

### 小地图图例

| 颜色 / 形状 | 含义 |
|---|---|
| 青色圆 | 当前安全区 |
| 白色细圆 | 下一个安全区 |

| 红色点 | 侦察镜发现的敌人 |

## 战斗反馈

- **受击方向**：屏幕边缘的红色弧指向最后一次受击来源
- **击杀播报**：右上角滚动，玩家击杀时击杀者名字显示为橙色
- **命中标记**：普通命中红色，爆头橙色且更大
- **枪口火焰**：每次开火在枪口生成短促火光
- **弹着点**：命中处生成尘土扩散
