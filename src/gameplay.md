# 操作与 HUD

## 一局比赛

1. 运输机沿随机航线飞越岛屿，航线显示在小地图和全屏地图上
2. 按跳跃键跳伞；不跳则在航线接近陆地边缘时自动跳伞
3. 自由落体可控制方向，按跳跃键提前开伞，约 70 米自动开伞
4. 落地后搜集武器、瞄具、医疗包
5. 安全区分 5 个阶段收缩，圈外持续掉血；缩圈计时在落地后开始
6. 活到最后一名获胜；死亡后显示击杀数和名次

## 开始界面

启动后先进入菜单：

- **模式**：大逃杀 / 训练场
- **难度**：简单 / 普通 / 困难，影响 AI 反应时间、伤害、扩散和射速
- **皮肤**：11 套，右侧实时 3D 预览
- **设置**：灵敏度 / 音量 / 开镜模式 / 陀螺仪
- **开始**

## 训练场

- 无限弹药，不用捡弹
- 7 个靶子，命中数显示在右上角
- 武器箱、瞄具、护甲、手雷、医疗包摆在两侧
- 没有 AI、没有缩圈，适合测试配件和手感

## 死亡观战

- 被淘汰后，结算面板提供「观战击杀者」
- 观战时可切换目标，或直接再来一局

## 运输机与跳伞

- 开局在 190 米高空登上运输机，飞机以 80m/s 沿随机航线飞越岛屿
- 航线显示在小地图和全屏地图上；可以自由选择跳伞时机和落点
- 跳跃键跳伞；如果一直不跳，飞机接近陆地边缘时会强制跳伞
- 开伞前是自由落体：摇杆/方向键控制方向，向前推会加速俯冲
- 跳跃键可以提前开伞；高度约 70 米时自动开伞
- 弧形翼伞：中央彩色伞面、白色翼尖和前缘、气室接缝与 10 根悬挂线
- 开伞有 0.35 秒展开动画和轻微摆动，落地自动收伞
- 伞面颜色跟随当前皮肤：天蓝 / 丛林 / 沙漠 / 赤红
- 落水会直接在水面着陆并进入游泳状态

> 空中会暂停缩圈计时，落地后才开始第一轮等待。

## 游泳

- 进入深水后自动浮在水面，速度 3.4m/s
- 游泳时不能跳跃，但可以开枪和转视角
- 离开水面自动恢复步行
- AI 落水也会浮起来，继续向安全区移动

## 城区与桥

- 地图中固定有一座城区：十字路口、四栋 2/3 层可进入建筑（楼梯、床、桌子、衣柜）、路灯和广场
- 城区外围是草地和丘陵，适合远距离架枪
- 地图中央偏南有一个湖，湖上有一座带护栏的长桥，可以步行通过
- 小地图上用浅色短线标出桥的位置

## 触屏操作

局内动作按钮已全部改为矢量图标，不再显示中文文字。

| 操作 | 图标 |
|---|---|
| 移动 | 左下摇杆，推满自动冲刺 |
| 转视角 | 右半屏任意位置拖动 |
| 开火 | 星芒 / 枪口火焰，左右各一个 |
| 瞄准 / 开镜 | 圆形准星，点击保持，再点收镜 |
| 跳 / 开伞 | 向上双箭头 |
| 换弹 | 环形箭头 |
| 医疗 / 手雷 | 十字 / 手雷轮廓 |
| 切换武器 | 双向箭头 |
| 侦察 | 雷达弧线 |
| 视角 | 眼睛 |
| 配件 | 扳手 |
| 展开地图 | 点击左上小地图或「地图」按钮；桌面按 M |

### 自定义按键

- 设置 → **按键布局**
- 拖动任意图标或摇杆调整位置；松手自动保存
- 可以重置为默认布局
- 位置保存在 `user://settings.cfg` 的 `[layout]` 中，重启后保留
- 编辑模式会显示图标下方的中文名称，方便辨认；正常游戏中只显示图标

> 按钮在 2.5 秒内没有触摸时会自动淡到 35%，减少对视野的遮挡；任意触摸立即恢复。

## 装备

- **护甲**：拾取后获得 100 护甲，吸收 50% 伤害，HUD 下方蓝色条显示
- **手雷**：最多 3 颗，投掷后 2.6 秒爆炸，6m 范围伤害
- **医疗包**：最多 3 个，回 40 HP
- **瞄具**：红点 / 4 倍 / 8 倍，拾取后在配件面板切换

## 设置

右上角「设置」：

- 灵敏度 0.3–2.0
- 主音量 0–100%
- 开镜模式：点击开镜 / 按住开镜
- 陀螺仪开关

设置保存在 `user://settings.cfg`，重启后保留。

> 「瞄准」是切换式：点一下进入开镜并保持，再点一下收镜。切枪或打开配件面板会自动收镜。
> 桌面端右键仍然是按住开镜。

## HUD

- **左上**：小地图（当前圈、下一个圈、玩家朝向、物资、房区）、FPS
- **顶部**：缩圈倒计时与半径
- **右上**：存活数、击杀数、击杀播报、换肤按钮
- **左下**：血量、医疗包数量
- **右下**：双武器槽、弹药、武器名与当前瞄具
- **中央**：准星、命中标记、受击方向弧、侦察标记

## 大地图

点击左上角小地图（或小地图下方的「地图」按钮）会从右侧滑出地图面板，
**左侧环境保持可见**，不会用全屏暗色遮住战场：

- 显示整张岛、当前安全区（青色）、下一个安全区（白色）
- 所有房区/城区、桥、武器箱、医疗包、瞄具、护甲、手雷
- 侦察镜发现的敌人会以红点显示
- 白色三角是玩家位置和朝向

地图操作：

- **双指捏合** / 鼠标滚轮 / 底部「+」「−」缩放（1.0×–3.5×）
- **单指拖动**地图平移；只有放大后才能平移
- 「1×」恢复全图；「定位」把地图移到玩家位置
- 点击右上角「×」关闭；点击左侧环境区域也会关闭；桌面按 M 开关

展开地图时会暂时锁定移动/开火，但**游戏不会暂停**，缩圈和 AI 照常进行。

## 战斗反馈

- **受击方向**：屏幕边缘的红色弧指向最后一次受击来源
- **击杀播报**：右上角滚动，玩家击杀时击杀者名字显示为橙色
- **命中标记**：普通命中红色，爆头橙色且更大
- **枪口火焰**：每次开火在枪口生成短促火光
- **弹着点**：命中处生成尘土扩散
