# 已知限制与路线

## 已知限制

- 美术是程序化方块小人 + 圆锥树，没有骨骼动画和贴图
- 枪声/脚步/换弹已使用真实录音；UI、爆炸、鸟叫和环境音仍是合成占位
- AI 是轻量状态机：没有导航网格，靠直线走位、射线检测和卡墙检测
- 没有载具、没有背包、没有多人和存档
- 房区是单层建筑，没有楼梯和二层（城区建筑有窗户和门框）
- 地形只加载玩家周围 7 × 7 个区块（约 540m），相机远平面 620m
- 地图支持缩放/平移，但暂不支持放置标记或路线规划
- debug APK 需要手机允许安装未知来源应用

## 下一步候选

### 战斗深度

- 护甲 / 头盔，按耐久吸收伤害
- 手雷 / 烟雾弹，配合房区攻楼
- 扩容弹匣、握把、枪口等更多配件，复用现有配件面板

### AI

- `NavigationRegion3D` 寻路，替代直线走位
- 会进房、会绕掩体、会打药
- 难度分级（反应时间、命中率、伤害）

### 表现

- 真实音效替换合成占位素材（保持现有文件名即可）
- 枪口动态光、弹壳、命中血雾
- 昼夜 / 天气、水面 shader
- 角色换骨骼模型和动画

### 平台与体验

- 陀螺仪辅助瞄准
- 音量 / 灵敏度 / 视角设置页，持久化到 `user://`
- 开始界面：难度、皮肤、视角、灵敏度
- 死亡后观战击杀者
- 战绩与解锁

### 内容

- 更多房区类型和大型 POI（写字楼、地铁口）
- 载具（越野车 / 船），城区道路已经预留
- 空投箱
